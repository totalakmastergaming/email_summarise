    Failover & workload

    Mail is split into batches and sent to your keys in priority order:

    • Priority order: Priority 1 keys are used first. Priority 2 and lower are standby if a higher-priority key is unavailable.
    • Rate-limit cooldown: If a key returns a rate-limit error (429), it is paused for a while and the next key is used instead.
    • Masked keys: Only masked key values are shown here. Full keys are stored server-side.
